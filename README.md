# BunkMaster 🎓

### Smart College Attendance Manager

BunkMaster is a simple, privacy-friendly attendance management web app designed for college students. It helps you track attendance, calculate how many classes you can safely bunk, and understand how many classes you need to attend to reach your target.

## ✨ Features

- 📊 **Overall Attendance Dashboard**
  - View your current attendance at a glance.
  - Track attendance across multiple subjects.

- 🛡️ **Can I Bunk?**
  - Set your attendance target.
  - Calculate the maximum number of classes you can miss safely.
  - See your projected attendance after bunking.
  - Find how many classes you need to attend to recover.

- 📚 **Subject Management**
  - Add, edit, and delete subjects.
  - Set individual attendance targets.
  - Track attended and conducted classes.

- 📅 **Upcoming Classes Simulator**
  - Enter the number of upcoming classes.
  - Calculate maximum possible bunks.
  - See projected final attendance.

- ↩️ **Undo Attendance**
  - Undo the latest attendance update.
  - Restores attendance counts and history.

- 📝 **Attendance History**
  - View your previous attendance records.
  - Filter between Present and Absent.

- 💾 **Local Data Storage**
  - Data is stored locally in your browser.
  - No account or login required.
  - No backend or database.

- 📦 **Backup & Restore**
  - Export your attendance data as JSON.
  - Import previously exported data safely.

- 📱 **PWA Support**
  - Install BunkMaster on Android and supported devices.
  - Works like an app directly from the browser.

- 🌙 **Responsive UI**
  - Designed for desktop and mobile.
  - Supports light and dark themes.

## 🛠️ Tech Stack
